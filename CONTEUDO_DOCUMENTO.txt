CAMPO: Metodologia
--------------------------------------------------------------------------------
A metodologia utilizada no desenvolvimento do Programa de Feedback Estudantil seguiu uma abordagem estruturada em etapas sequenciais, desde o levantamento de requisitos até os testes finais e a aplicação prática na comunidade. A tecnologia principal utilizada foi a linguagem de programação Python, com o framework web Flask e o banco de dados SQLite. A interface com o usuário foi desenvolvida utilizando HTML5, CSS3 e JavaScript.

CAMPO: Resultados Esperados/Obtidos
--------------------------------------------------------------------------------
O desenvolvimento do Programa de Feedback Estudantil alcançou resultados práticos expressivos na promoção do diálogo educacional. O sistema web foi plenamente implementado utilizando a linguagem de programação Python com o framework Flask e banco de dados SQLite. A aplicação permite que os estudantes avaliem o corpo docente de maneira totalmente anônima, atribuindo notas de 1 a 5 estrelas nos critérios de Didática, Pontualidade, Domínio do Conteúdo e Relacionamento com Alunos, além de fornecerem comentários textuais específicos para pontos positivos e aspectos a melhorar.

Para os professores, foi disponibilizado um painel exclusivo acessado por código individual, no qual é possível visualizar relatórios em tempo real contendo a média geral, as médias segmentadas por critério, gráficos comparativos de desempenho e a relação de considerações deixadas pelos estudantes. Essa devolutiva estruturada oferece subsídios concretos para que os docentes aprimorem suas práticas pedagógicas.

O projeto foi validado e aplicado no contexto de instituições de ensino no município de Vitória da Conquista - BA, consolidando um canal de comunicação respeitoso e objetivo entre discentes e docentes, colaborando diretamente com a meta do ODS 04 (Educação de Qualidade).

CAMPO: Considerações Finais
--------------------------------------------------------------------------------
O desenvolvimento da Atividade Extensionista proporcionou aprendizados técnicos e sociais fundamentais para nossa formação:

1. Desenvolvimento prático de software de ponta a ponta: Aprendemos a conceber, estruturar e implementar uma aplicação web completa utilizando a linguagem Python, o microframework Flask e banco de dados relacional SQLite, integrando banco de dados, regras de negócio e interface responsiva para resolver um problema real.

2. A tecnologia como propulsora da qualidade educacional: Compreendemos o papel da inclusão digital e dos sistemas computacionais na mediação pedagógica, constatando como um ambiente de avaliação anônimo e estruturado estimula o diálogo franco e construtivo, impactando positivamente a educação local.

3. Gestão colaborativa e trabalho em equipe: Aprimoramos competências interpessoais ligadas à distribuição equilibrada de tarefas, versionamento conjunto de código e resolução colaborativa de problemas técnicos, alinhando prazos às metas extensionistas.

4. Sensibilidade às demandas da comunidade: O contato com a realidade educacional de Vitória da Conquista reforçou a importância de planejar ferramentas de tecnologia centradas no usuário final, garantindo que o software seja simples, acessível e gere valor social palpável.
